# Smart Mall Parking System

A parking management system designed to help visitors find suitable parking slots in a shopping mall.

## Planned Features

- Parking slot availability monitoring using Computer Vision
- Parking recommendations based on vehicle type and user requirements
- Shortest-path navigation using Dijkstra's algorithm
- Admin dashboard for parking slot management
- Occupancy statistics and parking status updates

## Technology Stack

- **Frontend:** React.js
- **Backend:** Node.js and Express.js
- **Database:** MongoDB
- **Computer Vision:** Python, OpenCV and YOLO
- **Algorithm:** Dijkstra's shortest-path algorithm

## Project Structure

- `client/` — React frontend
- `server/` — Express backend and database integration
- `cv-service/` — Python Computer Vision service
- `docs/` — Project documentation
